# استمارة تحكيم الفكرة البحثية بالسيمنار

تطبيق ويب (React + Vite) لتحكيم الأفكار البحثية في سيمنار الدراسات العليا، ويعمل بالكامل داخل المتصفح (تُحفظ البيانات في localStorage).

## التشغيل محليًا
```
npm install
npm run dev
```

## النشر على GitHub Pages
1. ارفع محتويات المجلد إلى مستودع GitHub (الفرع `main`).
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. عند كل `push` يبني workflow الموقع وينشره تلقائيًا على `https://USERNAME.github.io/REPO/`.
